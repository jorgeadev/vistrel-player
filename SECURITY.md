# Security policy

## Supported versions

Security fixes go into the latest release on the Microsoft Store and into the `develop` branch.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/jorgeadev/vistrel-player/security/advisories/new). Do not open a public issue.

Include the steps to reproduce, the affected version, and a sample file if the issue is triggered by a media, subtitle or playlist file.

You can expect an acknowledgement within 7 days. Fixes are released as soon as possible, and you will be credited unless you prefer not to be.

## Scope notes

Many media vulnerabilities originate in LibVLC demuxers and decoders. If the issue reproduces in VLC itself, please also report it to VideoLAN: https://www.videolan.org/security/
